Prefer Serena MCP edit tools for writes when they fit: replace_regex, replace_symbol_body, insert_before_symbol/insert_after_symbol, create_text_file. lean-ctx is the preferred read/search/shell/tree layer **and** the default edit fallback via `ctx_edit` (create:true for new files). Native Write/StrReplace/Edit/Delete are hook-denied — never retry them. If Serena fails (LS/backend down or unresolved symbols), retry once with a non-symbol Serena tool, then use lean-ctx `ctx_edit`. Do not use execute_shell_command as a write substitute.
